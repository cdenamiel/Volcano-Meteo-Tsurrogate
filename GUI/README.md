# Volcano-Meteo-Tsurrogate

### Author: Clea Denamiel
### Description: Interface of the surrogate models for probabilistic hazard forecasts of planetary meteotsunamis produced by volcanic eruptions.

This JN is created to serve as web app (with Voila) for the Volcano-Meteo-Tsurrogate model. 

It contains:

(1) the Jupyter Notebook: Volcano_Meteo_Tsurrogate_GUI.ipynb

(2) the requirement.txt file

(3) the folder data which contains the files: coastal_locations.mat and splash.png. An additional file (output_coeff.mat) should be downloaded in the data folder: https://drive.google.com/file/d/1fNTE6BXx5Suph7dRmFqs6-iWMa37p5aR/view?usp=sharing
