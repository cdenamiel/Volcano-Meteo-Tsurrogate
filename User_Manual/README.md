The folder contains the user munual as a Jupyter Notebook (JN) named User_Manual.ipynb and three main sub-folders, **data**, **figures** and **results**.  <br>

## data

The user manual illustrates the usage of the Volvcano-Meteo-Tsurrogate software for 11 volcanoes used as test cases.

The folder data contains the files needed to run these test cases:

(1) **surrogate_model_locations.mat** file (already provided with the package) <br>
(2) **input_simus.nc** containing the deterministic model results needed to run the test cases. It must be downloaded from: https://drive.google.com/file/d/19oAWVE9gREZxL_0gu8YIhL6dMLfoRpYU/view?usp=sharingk <br>
