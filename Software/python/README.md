## code

The following user-oriented programs are provided:

- **Volcano_Meteo_Tsurrogate_step_1_user_input.py**
- **Volcano_Meteo_Tsurrogate_step_2_input_parameters.py**
- **Volcano_Meteo_Tsurrogate_step_4_format_simulations.py**
- **Volcano_Meteo_Tsurrogate_step_5_coefficients.py**
- **Volcano_Meteo_Tsurrogate_step_6_bis_visualization.py**
- **Volcano_Meteo_Tsurrogate_step_6_evaluation.py**
- **Volcano_Meteo_Tsurrogate_step_7_PMTHA.py**

For **more information** on how to use the code, consult the **user manual** provided in the package.

## data

By default the code is setup for 11 volcanoes used as test cases.

The folder data contains the files needed to run these test cases:

(1) **surrogate_model_locations.mat** file (already provided with the package) <br>
(2) **input_simus.nc** containing the deterministic model results needed to run the test cases. It must be downloaded from: https://drive.google.com/file/d/19oAWVE9gREZxL_0gu8YIhL6dMLfoRpYU/view?usp=sharingk <br>
